Algorithms and Data Structures

For this enhancement, I expanded the Android inventory management application with search and sorting functionality. Users can now search inventory records by item name and sort the displayed results to locate and organize inventory information more efficiently.

The completed enhancement demonstrates the application of algorithms and data structures while maintaining application state so that searching and sorting work together without resetting filtered results.

Databases
