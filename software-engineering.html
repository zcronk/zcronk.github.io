Artifact Overview

The artifact selected for the Software Design and Engineering category is an Android inventory management application originally developed as part of my Computer Science coursework at Southern New Hampshire University.

The application allows users to log in and manage inventory records stored in a local SQLite database. The original application provided functionality for displaying inventory, adding new inventory items, and deleting existing items.

I selected this artifact for my CS 499 ePortfolio because it provides an opportunity to demonstrate my ability to evaluate an existing application, identify an area where its usability could be improved, and integrate additional functionality without disrupting its existing features.

Software Engineering Enhancement

The primary enhancement to the application was the addition of inventory editing functionality. In the original application, an inventory record could be added or deleted, but an existing record could not be modified. Correcting an inventory value therefore required deleting the record and creating it again.

The enhanced application allows users to select an existing inventory item, modify its information, and save the updated values to the SQLite database. The inventory display then reflects the updated information without requiring the user to recreate the item.

The enhancement required changes across multiple parts of the application, including the user interface, application logic, database operations, and the interaction between those components. Existing add and delete functionality was preserved while the new editing capability was incorporated into the application's established workflow.

Skills Demonstrated

This enhancement demonstrates several software design and engineering skills developed throughout the Computer Science program.

  • Evaluating an existing software application and identifying opportunities for functional improvement
  • Extending an existing Java codebase while maintaining previously implemented functionality
  • Developing Android user interfaces using XML layouts and Java application logic
  • Integrating application functionality with a local SQLite database
  • Implementing database update operations for existing inventory records
  • Designing user interactions for editing and maintaining inventory data
  • Applying input validation and providing user feedback during inventory operations
  • Testing new functionality while verifying that existing application behavior remains intact

Course Outcomes

Course Outcome 3

The enhancement supports Course Outcome 3 by demonstrating my ability to evaluate an existing application's design and make engineering decisions that balance additional functionality with the complexity introduced by those changes.

Rather than redesigning the application unnecessarily, the enhancement extends the existing inventory workflow by adding editing functionality while preserving the application's original add, display, and delete capabilities.

Course Outcome 4

The enhancement supports Course Outcome 4 through the use of well-founded tools and techniques in computer science. Android development, Java, XML layouts, SQLite, and software engineering practices were used together to provide additional value to the user by making inventory records easier to maintain.

Enhanced Artifact

The completed enhancement adds inventory editing to the existing Android application and integrates the new functionality with the application's inventory display and SQLite database.
